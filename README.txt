To publish on your existing GitHub Pages site:
1. Open your repository on GitHub.
2. Upload BOTH files into the same folder (usually the repository root). Keep the video filename unchanged.
3. Commit the changes.
4. Open Settings → Pages and confirm the publishing branch/folder matches where index.html is stored.
5. Open your existing GitHub Pages URL and refresh. If it doesn't update immediately, wait a minute and refresh again.

Note: This is a static webpage. It does not send messages or collect information. The goodbye note is intentionally gentle and does not ask for a reply.
